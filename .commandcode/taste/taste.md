# Taste

## Workflow

- Wants all implementation code contained in the project's single designated implementation folder (e.g. `02_implementation`), not scattered across other project directories. Confidence: 0.65
- Expects each finished agent/app to be deployed to Vercel and the live URL handed back as part of "done". Confidence: 0.5
- Prefers generated test cases kept in their own dedicated folder (split into per-area files with an index), separate from the prompt/spec document rather than inlined in it. Confidence: 0.55
